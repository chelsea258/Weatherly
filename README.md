# 🌤️ Weatherly

> **A modern, responsive weather application built with HTML, CSS, and JavaScript.**

Weatherly is a clean and elegant weather application that provides real-time weather information for cities around the world. Built using the Open-Meteo API, it features a modern glassmorphism interface, dynamic weather backgrounds, hourly and 5-day forecasts, geolocation support, and persistent user preferences.

---



## ✨ Features

- 🔍 Search weather by city name
- 📍 Get weather using your current location
- 🌡️ Current temperature and "feels like" temperature
- 💧 Humidity, wind speed, and atmospheric pressure
- ⏰ Hourly weather forecast
- 📅 5-day weather forecast
- 🌤️ Dynamic weather icons
- 🖼️ Beautiful full-screen weather background
- 🌙 Light/Dark mode with saved preference
- 🕘 Recent search history using Local Storage
- 📱 Fully responsive design
- ⚡ Fast, lightweight, and API-driven

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Weatherly.git
```

Navigate into the project:

```bash
cd Weatherly
```

Open the project with your preferred code editor.

If you're using VS Code:

```bash
code .
```

Launch the project using Live Server or simply open `index.html` in your browser.

---

## 🎯 Usage

1. Enter the name of any city.
2. Click **Search**.
3. View the current weather conditions.
4. Explore the hourly and 5-day forecasts.
5. Use **Use My Location** to display weather for your current location.
6. Toggle between Light and Dark mode using the theme button.

## 🌍 APIs Used

### Open-Meteo Forecast API

Provides:

- Current weather
- Hourly forecast
- Daily forecast
- Weather codes
- Wind speed
- Pressure
- Humidity

### Open-Meteo Geocoding API

Converts city names into latitude and longitude coordinates.

During development several challenges were addressed:

- Integrating multiple Open-Meteo endpoints
- Mapping weather codes to readable descriptions and icons
- Managing asynchronous API requests with async/await
- Persisting user preferences using Local Storage
